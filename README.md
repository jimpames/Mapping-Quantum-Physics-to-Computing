# The Emergent Spacetime Rendering Engine

**A systems-theoretic research program mapping quantum physics to computational architecture.**

---

## What This Is

This repository contains a formal research program that models macroscopic three-dimensional spacetime, continuous motion, and rest mass as *emergent computational artifacts* generated by a discrete, sequential update loop operating on a lower-dimensional holographic boundary. It includes a formal paper, a Python simulation engine, a series of technical reports extending the framework into thermodynamics, fluid dynamics, and quantum information, a companion paper resolving quantum paradoxes, and extensive visualizations and media.

**All work is offered as a heuristic research program — not a claim of ontological truth.** See [Epistemic Status](#epistemic-status) below.

---

## Epistemic Status

This framework maintains a strict distinction between two claims:

| Claim | Description | Status |
|---|---|---|
| **Heuristic** | Reality can be *modeled as if* it were a framestacked rendering pipeline. | Defended in the paper |
| **Ontological** | Reality *is literally* a computational rendering engine on a 2D boundary. | Speculative research program |

The paper primarily defends the **heuristic claim** as a pedagogical and analytical tool. The **ontological claim** is framed as a candidate research program to be constrained by empirical observation. No derivation of Einstein's field equations or the Standard Model from the framestack update rule is claimed.

## Core Thesis

Macroscopic three-dimensional spacetime, continuous motion, and rest mass are conventionally treated as fundamental physical entities. This framework proposes an alternative: they are **emergent computational artifacts** of a discrete state update loop operating on a lower-dimensional boundary manifold.

### Formal Core Model

Let $\mathcal{B}$ represent the Hilbert state space of a two-dimensional boundary manifold. The evolution of the universe is modeled as a discrete state update:

$$B_{n+1} = F(B_n), \quad B_n \in \mathcal{B}$$

A phenomenological projection operator $\Pi(B_n)$ projects two-dimensional boundary states onto emergent three-dimensional bulk fields via Multiscale Entanglement Renormalization Ansatz (MERA) tensor network contractions. Rendering tax $C[B_n]$ is a cost functional over the bulk projection, and mass $m$ is interpreted as localized resistance to changing $\Pi(B_n)$:

$$m \sim \frac{1}{c^2} \frac{\delta C}{\delta \Pi}$$

## Falsifiability & Test Beds

To qualify as a physical theory, the framework must yield testable deviations from standard physics. Four candidate signatures are proposed:

1. **Planck-Scale Dispersion** — High-energy cosmic photons may exhibit energy-dependent arrival time delays.
2. **Holographic Noise** — Laser interferometers may detect spacetime jitter induced by boundary quantization.
3. **Sub-Millimeter Gravity Deviations** — Short-distance tests may detect corrections to Newton's law.
4. **Complexity Bounds** — Quantum information systems may reveal complexity-theoretic limits on entanglement scaling.

The Python engine computes numerical predictions for the first three test beds. These are **template calculations**, not derived predictions.
